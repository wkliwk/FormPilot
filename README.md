# FormPilot

AI-powered form assistant for PDF, Word, spreadsheet and web forms — parses complex forms, explains fields in plain language, and auto-fills from your stored profile.

## What it does

Upload a form (PDF, DOCX, image), and FormPilot extracts every field, categorizes the form (tax, immigration, legal, HR/employment, healthcare, general), and explains each field in plain language with an example value and common mistakes to avoid.

Built for people filling out confusing, high-stakes forms — W-4/1040, I-9/DS-160, legal, HR, government paperwork — where getting a field wrong is costly and the instructions are unclear.

## Stack

Next.js, Prisma, Claude + Gemini (multi-model form analysis), Playwright/Jest for testing, Sentry for monitoring, browser extension component. Deployed on Vercel.
